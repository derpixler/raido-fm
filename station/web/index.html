    RAIDO FM

    A Manifest for Autonomous AI Radio

    An open-source manifest for operating one or more digital radio stations entirely moderated and curated by an AI (Large Language Model). No script, no human in the loop — the LLM autonomously decides on playlists, writes moderation copy, reacts to listener feedback, and runs the station 24/7.
    24/7 Live
    ~5 EUR /Monat
    Unbegrenzt Stationen
    Architektur
    • DJ-Agent — autonome KI-Persoenlichkeit mit 60-Minuten-Programm-Grid
    • StreamGuard — 5-stufiges Sicherheitssystem gegen KI-Degeneration
    • Generative Host-Read Ads — keine MP3-Spots, KI-geschriebene Werbung
    • Quarantine-DB — Schutz vor Prompt-Injection bei externen Daten
    • Multi-Station — beliebig viele Sender parallel, je eigene Persoenlichkeit
    • Persistent Personality — Mood-State, Self-Notes, Recurring Quirks
    Tech Stack
    Groq/Llama 3 · Piper TTS · Icecast2 · ffmpeg · SQLite · FastAPI · Docker · Traefik
