Station Modes

RT Realtime — Real-time mode. 1 track minute = 1 real minute. Songs play at full length, moderations at normal speaking speed. Ideal for live operation.

SIM Simulation — Accelerated demo mode. TIME_SCALE=60x. 1 track minute = 1 second. Min. 5s per track, 3s per moderation. Ideal for testing and demonstrating.

The mode can be changed at any time. A running song/moderation will finish at the old speed.
